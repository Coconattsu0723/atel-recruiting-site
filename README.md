# ATEL Recruiting Site

`BEHIND THE SPACE`をコンセプトにした、架空の空間デザイン・施工会社ATELの採用サイトです。

## Pages

- HOME
- PEOPLE / Interview Dialog
- JOBS / Filtered / Empty State
- JOB DETAIL / 8 Roles
- ENTRY / Input / Confirm / Complete

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Build

```sh
npm run build
```

公開対象は`dist/`へ出力されます。`dist/`は直接編集せず、元ファイルを修正して再生成します。
