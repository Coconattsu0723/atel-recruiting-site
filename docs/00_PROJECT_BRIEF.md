## 4. 採用課題と目的

ATELは、完成した店舗や空間の実績は魅力的に見える一方で、求職者から見ると「どんな人が、どのように空間をつくっている会社なのか分かりにくい」という課題を持っている設定とする。

コーポレートサイトでは実績写真は見られるが、以下の情報が分かりづらい。

- どんな職種があるのか
- 職種同士がどう関わるのか
- 入社後どんな仕事をするのか
- どんな人が働いているのか
- 新卒と中途で何が違うのか
- 自分に合う募集があるのか

そのため採用サイトでは、**「働く姿を具体化し、自分に合う仕事を見つけてもらう」**ことを目的とする。

### 8.5 画像表現ルール

画像は単純な長方形だけで使用せず、使用する画像フレームを以下の4種類に限定する。

| フレーム | 用途 |
| --- | --- |
| Rectangle | 店舗写真 / 施工写真 / 情報系 |
| Circle | 人物写真 / 小さなアクセント |
| Polaroid | Interview / Culture / Behind the scenes |
| Organic Mask | Hero / 主役ビジュアル |

必要に応じて、以下の表現・実装も使用する。

- 少し傾ける
- 写真同士を重ねる
- hoverで拡大
- スクロールで出現
- CSS `border-radius`
- `overflow: hidden`
- `transform`
- `box-shadow`
- `clip-path`
- `mask-image`

**職種と色を連動させる案**

| 職種 | 色 |
| --- | --- |
| DESIGN | Blue |

**メインコピー**

> SPACE IS NEVER MADE ALONE.

- 無彩色寄りの開始
- スクロールとともに色が増える演出

### 10.2 MESSAGE

**見出し**

> BEHIND THE SPACE

完成した店舗の裏側には、たくさんの人と工程があることを伝える。巨大タイポ + 短いコピー中心とする。

### 10.3 HOW WE CREATE

店舗ができるまでを見せる。

`THINK → DESIGN → BUILD → OPEN`

**使用イメージ**

- 図面
- 素材サンプル
- 打ち合わせ
- 現場
- 完成店舗

Rectangle、Circle、Polaroid、Organic Maskの画像形式を混在させる。

### 10.4 PROFESSIONS

**見出し**

> 8 PROFESSIONS, ONE SPACE.

**想定表現**

- 横スクロール
- hoverで背景写真切替

### 10.5 PROJECT × PEOPLE

| 項目 | 内容 |
| --- | --- |

完成空間だけでなく、人と仕事の関係を見せることを目的とする。
